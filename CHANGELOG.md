# Changelog

## 1.0.1 — 2026-10-20

- Mobile reader swipes respond to shorter deliberate drags and quick rightward flicks, with a slightly wider left-edge start area and earlier gesture feedback.
- Preserve vertical and diagonal scrolling, controls, code/table scrolling, cancelled touches and short-drag safeguards.

## 1.0.0 — 2026-10-17

Initial public release, tested against FreshRSS 1.30.1.

- Responsive article cards with higher-resolution image selection and loading fallbacks.
- Native-state modal reader with keyboard navigation and mobile edge-swipe dismissal.
- Collapsed sidebar, explicit close control and hidden mobile bottom arrow bar.
- Neutral dark palette, muted headlines and dimmed images.
- Synthetic integration tests for PHP, browser behaviour, responsive layouts, images and touch gestures.
