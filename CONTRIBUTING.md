# Contributing

Please include the FreshRSS version, browser, theme, expected behaviour and a minimal reproduction when reporting an issue. Remove account names, feed credentials, private article content, tokens and internal server addresses from logs and screenshots.

Changes should remain inside this extension, keep production code dependency-free, and preserve native FreshRSS article state, pagination and extension hooks. Prefer supplied image variants to guessed publisher URLs.

Run the checks described in the README. Use synthetic content for tests and demo screenshots. Physical iPhone Safari/PWA testing is especially helpful; report the iOS version and whether you tested Safari or a home-screen installation.

Contributions are provided under the repository's MIT licence.
